# gas-export

Google Apps Scriptのソースを、設定ファイルに従ってローカルへ保存するPythonツールです。

`run.py` があるフォルダで実行し、設定・認証キャッシュ・取得用Chromeプロファイルを相対パスで指定します。

Windowsでは初回準備後、毎回 `run_export.bat` をダブルクリックするだけで取得できます。初回準備・必要時の保守・開発者向けのバッチは、日本語READMEで分類しています。

導入・設定・実行方法は [日本語README](README.ja.md) を参照してください。

現在は開発版です。Driveフォルダ探索にはブラウザ操作を使用し、GASのないファイルに空のプロジェクトが作成される場合があります。最初は少数のテスト用ファイルで確認してください。
